# Library Management System Database

## 📖 Description
A complete MySQL database for managing library operations including:
- Member/patron management
- Book catalog and inventory tracking
- Loan/borrowing system
- Fine calculation for overdue items
- Staff management

## 🛠️ Setup Instructions
1. Ensure MySQL Server is installed
2. Run the SQL file:
   ```bash
   mysql -u [username] -p < library_db.sql
